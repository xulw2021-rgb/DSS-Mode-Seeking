# Data directory

No raw datasets are bundled with this repository.

- CIGRE-14 and Oberrhein-70 scenarios: generated by the pandapower Monte-Carlo
  pipeline in `src/toy_network.py` (run from the repository root; output written
  under `data/<grid>/`). The frozen paper results used datasets generated with
  the validated protocol documented in docs/REPRODUCIBILITY.md.
- IEEE-30 scenarios: `python scripts/generate_ieee30_data.py --out-dir data/ieee30`.
- PanTaGruEl IEEE-14: external benchmark (Zenodo 10.5281/zenodo.5816149, CC-BY-4.0).
  Download with `python scripts/download_pantagruel.py --out external/pantagruel`,
  then convert with
  `python scripts/convert_pantagruel.py --src external/pantagruel/dataset_14_case_1.h5 --out-dir data/pantagruel_14_case1`.

The frozen publication results (results/final/) do not require any of these downloads.
